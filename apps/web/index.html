Transparency

What this rail does, what it refuses, and what is not live yet.

Warning: Arc consensus can swap bytecode

Arc validators still attest blocks with elliptic-curve signatures. If that underlay is corrupted, or if precompile 0x1800..0004 is made to lie, bytecode at a known address can be replaced without a contract-level owner call. On-Arc SLH checks then run on a lying chain. That risk is inherent to an EC-consensus L1. It is not closed by putting SLH in the contracts.

Fix: QRVM (ML-DSA-87) is the controlling verifier. Each messenger pins extcodehash of itself, its minter, and its transmitter. Every burn body carries a code seal over chain id, those addresses, and those hashes. QRL stores the expected Arc seal and will not mint on peer-seal or codehash mismatch. A second deploy of the same bytecode cannot impersonate the pinned messenger (addresses are in the seal). A swapped Arc implementation can still mutate Arc; it cannot mint on QRL unless the Dilithium owner also re-pins the seal.

How value moves

  1. Arc → QRL: native USDC is locked in TokenMinter (Circle USDC is never burned by ARQL, never wrapped).
  2. Message V2 is packed bytes64, not ABI. Relayer attests; QRL mints QRC-20 1:1.
  3. QRL → Arc: QRC-20 is burned; Arc unlocks the same native USDC.
  4. If QRL mint is rejected, Arc USDC stays in the lockbox. It is not minted on QRL, not returned automatically, not seizable. Retry is allowed; timeout refund is not (it would race a late mint).

Post-quantum controls

  • Arc admin: owner + guardian SLH-DSA must both sign. Pauser can halt only.
  • Arc attestation: 2-of-N SLH-DSA. 64/65-byte ECDSA is ecdsa-forbidden.
  • User deposits require a registered per-account SLH key.
  • QRVM txs are ML-DSA-87. secp256k1 cannot submit them.
  • This page is static. It does not sign and does not hold keys.

Sanctions and enterprise

  • Depositor, mint recipient, unlock to, and burn from are screened before value moves.
  • Compliance SLH can add names and freezes. Removing a name needs owner and guardian.
  • The Arc lockbox is not drained to a treasury. Seizing pooled escrow while a mint can still succeed would issue QRC-20 against missing USDC.
  • Circle FiatToken blacklist on official USDC remains independent. ARQL refuses earlier so we do not lock toward a name we will not mint to.
  • OFAC/SDN feeds stay off-chain and call sanction / freeze.
